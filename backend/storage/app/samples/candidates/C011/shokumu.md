■ 担当業務

Go で実装されたマイクロサービス群のうち、複数サービスの API の設計・実装・改修を担当しました。入社1年目は既存サービスの機能追加や不具合修正から始め、2年目以降は新規サービスの API 設計から実装までを主担当として進めました。

■ 主な取り組み

- Go による API 開発：3年間、日常的な開発言語として使用し、機能追加、改修、不具合調査、コードレビューを継続して担当しました。処理の責務を小さく分けて読みやすく保つことを意識し、レビューで挙がった指摘を次の実装に反映してきました。
- Docker によるローカル開発環境の整備：複数のサービスを開発者の端末でまとめて起動できる構成を整え、利用手順を資料にまとめました。新しく加わったメンバーが短い時間で開発を始められるようになりました。
- gRPC によるサービス間通信の実装：サービス間のインターフェース定義を取り決め、呼び出し側と提供側の双方を実装しました。エラー時の扱いについても、関係するメンバーと相談して揃えました。

## 自己PR

私の強みは、Go を使ったバックエンド開発を3年間継続し、API の設計から実装、改修までを安定して進められることです。入社当初は既存サービスの小さな修正から始め、徐々に担当範囲を広げて、新規サービスの API を主担当として任されるようになりました。

次に、開発しやすい環境づくりへの意識です。Docker でローカル開発環境を整備した際には、構成を整えるだけでなく、手順を資料にまとめ、誰でも同じ状態で開発を始められることを重視しました。その結果、新しく加わったメンバーの立ち上がりを支えることができました。

また、gRPC によるサービス間通信の実装では、他のサービスの担当者と認識を合わせる場面が多くありました。インターフェースやエラー時の扱いを早めに相談して揃えることで、手戻りを減らすよう心がけています。

一方で、コンテナの本番運用は経験がありません。この分野はインフラ担当の方々から学びつつ、運用まで見据えた設計ができるよう、引き続き成長していきたいと考えています。
