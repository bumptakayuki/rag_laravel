## 職務経歴

【株式会社サンプルクラウド】2019年4月〜現在
事業内容：自社サービスおよび受託システムの開発・運用
担当職種：SRE

入社以来、Google Cloud 上に構築された本番環境の運用を担当しています。開発チームと協力しながら、サービスの安定稼働と、リリース作業の効率化に取り組んできました。

- Google Cloud 上の本番環境の運用を6年間継続して担当
- コンテナオーケストレーション基盤で、数十のサービスの稼働状況を管理
- 各サービスのマニフェストを一元的に管理し、レビューを経て本番へ反映する流れを整備
- デプロイの手順を自動化し、手作業による反映作業を減らして、リリース時のミスを防ぎやすくした
- Prometheus と Grafana で監視を整備し、サービスごとのダッシュボードとアラートを設計・運用
- 障害発生時は Slack で状況を共有しながら一次対応を行い、収束後に原因と再発防止策を整理して関係者へ報告

監視の整備によって、利用者に影響が出る前に異常へ気づける場面が増えました。また、マニフェストの管理とデプロイの自動化を通じて、サービス数が増えても運用の手順が大きく変わらない状態を保つことを意識してきました。
