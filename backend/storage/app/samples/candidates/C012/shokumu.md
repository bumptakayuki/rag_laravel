# 職務経歴書

## 職務要約

フロントエンドエンジニアとして8年の実務経験があります。Vue.js と Nuxt を主力技術として、メディアサイトと EC サイトのフロントエンド開発に一貫して携わってきました。

表示速度の改善とアクセシビリティ対応を継続して担当し、利用者が快適にサイトを使える状態を保つことに取り組んできました。また、既存の JavaScript のコードベースから TypeScript への移行を主導し、型の方針づくりから段階的な置き換え、チームへの定着までを進めました。

画面の実装だけでなく、品質や保守性の向上にも関心を持ち、デザイナーやバックエンド担当者と連携しながら開発を進めることを得意としています。

## 職務経歴

【株式会社サンプルメディア】2016年4月〜2020年3月
事業内容：ニュース記事と読み物を配信するメディアサイトの運営
担当：フロントエンドエンジニア

- Vue.js と Nuxt を用いて、記事一覧、記事詳細、検索結果、特集ページなどのフロントエンドを開発
- 表示速度の改善を担当。画像の読み込み方法の見直し、不要なスクリプトの整理、初期表示に必要な処理の絞り込みを実施
- アクセシビリティ対応を担当。見出し構造の整理、画像の代替テキストの運用ルール化、キーボード操作と色のコントラストの確認を実施
- 画面部品の共通化を進め、新しい特集ページを短い期間で公開できる体制づくりに貢献

【サンプルコマース株式会社】2020年4月〜現在
事業内容：衣料品と雑貨を扱う EC サイトの運営
担当：フロントエンドエンジニア

- Vue.js と Nuxt を用いて、商品一覧、商品詳細、カート、購入手続きなどの画面を開発
- 表示速度の改善を担当。商品画像の最適化、ページごとの読み込み内容の見直しにより、一覧や詳細ページの表示体験を改善
- アクセシビリティ対応を担当。フォームのラベルやエラーメッセージの表示方法を見直し、購入手続きを支援技術でも操作しやすいように改善
- JavaScript から TypeScript への移行を主導。移行の方針と優先順位を決め、新規開発から順に適用し、既存コードを段階的に置き換えた
- 移行にあたり、型の書き方をまとめた資料を作成し、コードレビューや勉強会を通じてチームに定着させた

## 自己PR

私の強みは、利用者の使いやすさと開発チームの働きやすさの両面から、フロントエンドを改善し続けてきたことです。

1. 長期の実務に基づく技術力
Vue.js と Nuxt を主力として8年間、メディアサイトと EC サイトの開発に携わってきました。性質の異なる二つのサイトを経験したことで、情報を読みやすく見せる設計と、購入までの流れを止めない設計の両方を身につけました。

2. 継続的な品質改善
表示速度の改善とアクセシビリティ対応を、一度きりの対応で終わらせず、日常の開発に組み込むことを心がけています。確認の観点をチームで共有し、新しい画面でも同じ水準を保てるようにしてきました。

3. 変化を進める推進力
JavaScript から TypeScript への移行を主導しました。一度にすべてを置き換えるのではなく、優先順位を決めて段階的に進め、資料づくりやレビューを通じてチームの理解を得ながら定着させました。

今後も、利用者にもチームにも信頼されるフロントエンド開発を続けていきたいと考えています。
