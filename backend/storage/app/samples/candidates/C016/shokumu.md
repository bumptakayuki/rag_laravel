## 職務要約

Web アプリケーションのテスト設計とテスト自動化を5年間担当してきた QA エンジニアです。

1社目の株式会社サンプルテックでは、業務向け Web システムの手動テストの設計と実施を経験したあと、Selenium による E2E テストの自動化に取り組みました。2社目のテストサンプル株式会社では、会員向け Web サービスのテスト設計を担当しながら、Playwright を使った E2E テストの仕組みを新規に構築しました。あわせて、既存の Selenium テストの一部を Playwright へ移行しました。

JSTQB Foundation Level を保有しており、体系的なテスト技法にもとづいて、不具合を早い段階で見つけるテスト設計を心がけています。

## 自己PR

私の強みは、テスト設計と自動化を切り離さずに考えられることです。自動化できるかどうかではなく、どのリスクをどの手段で確認すべきかから考え、手動テストと自動テストの役割を整理します。この考え方により、Playwright で構築したテストを、少ない保守の負担で運用できています。

また、Selenium で長く自動化を担当した経験から、テストが不安定になる原因や、保守しにくいテストの特徴を把握しています。Playwright への移行では、単にテストを置き換えるのではなく、重複するシナリオの整理や待機処理の見直しを行い、テスト全体を安定させました。

さらに、開発者や企画担当者と仕様の曖昧な点を早めに確認し、テスト設計の段階で問題を指摘することを大切にしています。今後も、チーム全体で品質を高められる QA として貢献していきます。
