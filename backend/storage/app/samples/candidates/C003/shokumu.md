## 職務要約

大学卒業後、株式会社サンプルクラウドにフロントエンドエンジニアとして入社し、4年間、SaaS の管理画面の開発に携わってきました。TypeScript と React を主力として使い、画面の新規開発や改修に加えて、デザインシステムの整備とコンポーネントのテストを担当しています。

また、バックエンドが Laravel のプロジェクトでは、半年ほど Blade テンプレートの修正と簡単な API 追加を手伝いました。こちらは補助的な関わりにとどまりますが、フロントエンドとバックエンドの役割分担を理解するうえで役立っています。

## 職務経歴

【株式会社サンプルクラウド】2021年4月〜現在

事業内容は法人向け SaaS の提供です。入社以来、フロントエンドエンジニアとして、顧客企業の担当者が日常的に使う管理画面の開発を担当しています。

SaaS 管理画面の開発（2021年4月〜現在）
- TypeScript と React を主力として、一覧・詳細・設定などの管理画面を継続的に開発
- 要件の確認から実装、レビュー対応、リリース後の改修まで一通りを担当
- 型定義を活用し、画面間のデータの受け渡しで起こりがちな不具合を未然に防ぐ実装を心がけた
- デザイナーやバックエンド担当者と Slack で相談しながら、仕様の調整を進めた

デザインシステムの整備
- 画面ごとに異なっていたボタンや入力フォームなどの見た目と挙動を整理し、共通コンポーネントとして集約
- 利用ルールや使い方の例を文書にまとめ、新しく参加したメンバーでも迷わず使えるようにした
- 開発メンバーからの要望を聞き取り、コンポーネントの改善を継続

コンポーネントのテスト
- 共通コンポーネントを中心に、表示や操作の振る舞いを確認するテストを作成・保守
- 改修時に影響範囲を把握しやすくなり、レビューでの確認負担の軽減につながった

Laravel プロジェクトの支援（約半年）
- バックエンドが Laravel のプロジェクトで、Blade テンプレートの修正と簡単な API 追加を手伝った
- 担当は既存の仕組みに沿った小規模な変更が中心で、設計や運用を主導した経験はない

## 自己PR

長く使い込んだ TypeScript と React を土台に、見た目と品質の両面から管理画面を支えてきた点が強みです。

特にデザインシステムの整備とコンポーネントのテストでは、一度作って終わりにせず、使う側の声を聞きながら改善を続けてきました。共通部品の使い方を文書にまとめたことで、チーム全体で画面の統一感を保ちやすくなりました。

また、Laravel のプロジェクトを手伝った経験から、バックエンド担当者がどのような情報を必要とするかを意識して相談できるようになりました。深い専門性があるわけではありませんが、フロントエンドの立場から仕様を具体的に伝え、円滑に連携することを心がけています。
