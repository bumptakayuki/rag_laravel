# 求人票：バックエンドエンジニア（Go）

会社名：株式会社サンプルソリューションズ
募集職種：バックエンドエンジニア（Go）

## 募集概要

株式会社サンプルソリューションズでは、自社サービスの中核を支えるバックエンドエンジニアを募集します。Go で開発しているマイクロサービス群の機能追加や改善を、チームで進めていただくポジションです。

サービスの成長にあわせて、システムを小さな単位に分割し、保守しやすい構成へ育てていく段階にあります。Go の実務経験を活かし、設計から運用まで主体的に関わっていただける方を求めています。

- 募集職種: バックエンドエンジニア（Go）
- 雇用形態: 正社員
- 配属: プラットフォーム開発チーム（5〜8名）

## 業務内容

Go を用いたマイクロサービスの設計・開発・運用をお任せします。経験や志向に応じて、担当範囲を段階的に広げていきます。

- 既存マイクロサービスへの機能追加、不具合修正、性能改善
- 新規サービスの設計と実装、サービス間の連携方法の検討
- 単体テスト・結合テストの作成と、テストしやすいコードへの改善
- コードレビューの実施、設計方針に関するチーム内の議論への参加
- 障害発生時の原因調査と再発防止策の立案
- 仕様や設計意図をまとめたドキュメントの作成・更新

プロダクトマネージャーやフロントエンド担当と連携しながら、要件の整理から リリースまでを一貫して担当する機会もあります。

## 必須条件

- Go を用いた業務でのアプリケーション開発経験（目安として2年以上）
- マイクロサービス構成のシステムを開発した経験
- 他のメンバーが読みやすいコードを書き、コードレビューに対応できること
- 単体テストなど、品質を保つための開発手法を実務で取り入れた経験
- チームメンバーと円滑にコミュニケーションをとり、課題を共有できること

## 歓迎条件

- マイクロサービスの設計段階（サービスの分割方針の検討など）に関わった経験
- 本番環境での運用や障害対応の経験
- 性能のボトルネックを調査し、改善まで行った経験
- 小規模チームでのリード経験、または後輩メンバーの育成経験
- ドキュメントを整備し、知見をチームに広げる習慣があること
- 新しい手法を学び、業務に取り入れることに前向きな方

## 開発環境・働き方

開発言語は Go を中心としています。チーム内の連絡や相談には Slack を使い、仕様や設計の資料は Word や Excel で共有することもあります。

- 働き方: 在宅勤務と出社を組み合わせたハイブリッド勤務（週2〜3日の在宅勤務が目安）
- 勤務時間: コアタイムなしのフレックスタイム制
- 開発の進め方: 2週間ごとの振り返りを行い、改善を継続
- 学習支援: 書籍購入補助、社内勉強会の開催
- 休暇: 完全週休2日制、年次有給休暇、夏季・年末年始休暇

互いにコードレビューを行い、安心して挑戦できる雰囲気づくりを大切にしています。
