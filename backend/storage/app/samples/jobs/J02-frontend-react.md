# 求人票：フロントエンドエンジニア（React）

会社名：株式会社サンプルシステムズ
募集職種：フロントエンドエンジニア（React）

## 募集概要

株式会社サンプルシステムズでは、法人のお客様向け業務支援サービスの管理画面を開発する、フロントエンドエンジニア（React）を募集します。

管理画面は、お客様の担当者が日々の受発注、顧客情報、レポートなどを扱うサービスの中核です。使いやすさと保守のしやすさを両立させる必要があるため、TypeScript と React を使った開発を実務で経験してきた方を求めています。

- 職種：フロントエンドエンジニア（React）
- 雇用形態：正社員
- 配属：プロダクト開発部 フロントエンドチーム

## 業務内容

入社後は、既存の管理画面の機能改善と新機能の開発を中心にお任せします。

- 管理画面の新機能の設計・実装（一覧、検索、入力フォーム、グラフ表示など）
- 既存画面の改修、表示速度や操作性の改善
- TypeScript による型定義の整備と、コンポーネントの共通化
- バックエンドチームとの API 仕様の調整、および画面との連携実装
- コードレビューや画面仕様の検討会への参加
- 運用中の不具合の調査と対応

担当者は、企画担当者やデザイナーと相談しながら、画面の仕様を具体化する段階から参加します。

## 必須条件

- TypeScript と React を用いた Web アプリケーション開発の実務経験
- 管理画面や業務システムなど、データを扱う画面の実装に携わった経験
- チーム開発の経験（コードレビューを受ける、行う経験を含む）
- 他職種のメンバーと Slack などで円滑にやり取りし、仕様を確認しながら進められること

## 歓迎条件

- 管理画面の設計段階から関わり、画面の構成や操作の流れを提案した経験
- 複雑な入力フォームや大量データの表示を扱った経験
- コンポーネントの共通化や、画面のテストの整備に取り組んだ経験
- 既存コードを読み解き、少しずつ改善していくリファクタリングの経験
- 画面の使いやすさについて、利用者の声をもとに改善した経験

## 開発環境・働き方

開発は TypeScript と React を中心に進めています。フロントエンドチームは少人数で、メンバー同士の距離が近く、相談しやすい雰囲気です。

- 開発体制：フロントエンドチームと、バックエンド・企画・デザインの各担当が連携して進めます
- コミュニケーション：日々の連絡は Slack、仕様の共有は Word や Excel の資料も使います
- 開発の進め方：2週間ごとに計画と振り返りを行い、すべての変更にコードレビューを実施します
- 働き方：リモートワークと出社を組み合わせたハイブリッド勤務、フレックスタイム制
- 学習支援：書籍の購入補助や、社内勉強会への参加を歓迎しています
