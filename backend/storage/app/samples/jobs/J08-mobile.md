# 求人票：モバイルアプリエンジニア

会社名：株式会社サンプルモバイルワークス
募集職種：モバイルアプリエンジニア

## 募集概要

株式会社サンプルモバイルワークスでは、生活者向けの予約・会員管理アプリを自社サービスとして提供しています。このたび、iOS / Android 両方のアプリ開発を担うモバイルアプリエンジニアを募集します。

企画段階から開発、リリース後の改善まで一貫して関われるポジションです。少人数のチームで、職種を越えて意見を出し合いながら開発を進めています。

- 職種：モバイルアプリエンジニア
- 雇用形態：正社員
- 配属：モバイル開発チーム（現在5名）
- 給与：経験・スキルを考慮のうえ、面談時にご案内します

## 業務内容

自社サービスの iOS / Android アプリについて、新機能の開発と既存機能の改善をお任せします。まずは既存アプリの保守や小規模な改修から始め、慣れてきた段階で機能単位の設計・実装を担当していただきます。

- iOS / Android アプリの設計・実装・テスト
- 企画担当・デザイナーと連携した仕様の検討と画面設計の相談
- サーバー側の担当者と協力したデータ連携の調整
- 不具合調査、動作改善、利用状況をふまえた機能改善
- コードレビューへの参加と、開発手順やドキュメントの整備
- アプリのリリース作業と、リリース後の状況確認

## 必須条件

- Swift または Kotlin を用いた iOS / Android アプリの開発経験（実務で2年以上が目安）
- 企画や仕様をもとに、設計から実装・テストまでを自走して進められること
- 他職種のメンバーと、Slack や会議で円滑にコミュニケーションが取れること
- 他のメンバーが書いたコードを読み、レビューし合うことに前向きであること

## 歓迎条件

- iOS と Android の両方でアプリ開発に携わった経験
- Swift と Kotlin の両方で実務経験があること
- アプリを公開し、ストアの審査対応や公開後の運用を行った経験
- 利用者の声や利用状況をもとに、機能改善を提案・実行した経験
- 小規模チームでの開発リードや、後輩メンバーの支援経験
- 新しい開発手法を学び、チームに共有することが好きな方

## 開発環境・働き方

開発言語は iOS が Swift、Android が Kotlin です。チームでは担当を固定せず、得意分野を軸にしながら両方のアプリに関わる機会があります。仕様の相談や進捗の共有には Slack を使い、週1回の定例会で状況を確認しています。

- 勤務形態：フレックスタイム制（コアタイムあり）
- 勤務地：オフィス勤務を基本とし、在宅勤務も相談可
- 休日：土日祝日、年末年始、年次有給休暇
- 学習支援：書籍購入補助、社内勉強会の開催
- 開発体制：コードレビューを重視し、少人数で意思決定が早い環境
