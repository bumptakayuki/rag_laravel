# 求人票：バックエンドエンジニア（PHP / Laravel）

会社名：株式会社サンプルクラウド
募集職種：バックエンドエンジニア（PHP / Laravel）

## 募集概要

株式会社サンプルクラウドでは、自社で開発・提供している業務管理 SaaS のバックエンドを担うエンジニアを募集します。利用企業の増加にともない、API の機能拡張と品質向上を進める必要があり、PHP と Laravel で開発を支えてくださる方を求めています。

- 職種：バックエンドエンジニア（PHP / Laravel）
- 雇用形態：正社員
- 配属：プロダクト開発部 API チーム（5名）
- 勤務形態：オフィス出社とリモートの併用

## 業務内容

自社 SaaS の API 開発を中心に、設計から運用までを一貫して担当していただきます。

- 自社 SaaS の API の設計・実装・テスト
- 既存 API の改善、性能チューニング、不具合の調査と対応
- 新機能に向けたデータベース設計とマイグレーションの作成
- コードレビューへの参加と、開発ルールの整備
- フロントエンドチームやカスタマーサポートとの仕様調整
- API 仕様書や社内向けドキュメントの作成・更新

まずは既存機能の改修から担当していただき、チームの進め方に慣れた段階で新機能の設計をお任せします。

## 必須条件

- PHP と Laravel を用いた実務経験が3年以上ある方
- Laravel で API を設計・実装した経験がある方
- リレーショナルデータベースを使った開発経験がある方
- チーム開発でのコードレビューやバージョン管理の経験がある方
- 仕様を整理し、関係者と円滑にコミュニケーションを取れる方

経験年数に加えて、どのような規模・役割で開発に関わったかを面接でお聞かせください。

## 歓迎条件

- SaaS など、継続的に提供するサービスの開発・運用経験
- 自動テストの作成や、テストを前提とした開発の経験
- 大量データを扱う処理やパフォーマンス改善の経験
- 認証・認可を含む API のセキュリティ設計の経験
- 後輩メンバーの指導やチームでの技術的な意思決定の経験
- 既存コードのリファクタリングを計画的に進めた経験

## 開発環境・働き方

開発言語・フレームワークは PHP と Laravel を中心に利用しています。チーム内の連絡は Slack で行い、仕様や議事録は社内ドキュメントにまとめて共有しています。

- 開発体制：少人数のチームで、週1回の振り返りと隔週のリリースを実施
- 勤務時間：フレックスタイム制（コアタイムあり）
- 働き方：週2〜3日のリモートワークが可能
- 学習支援：書籍購入や外部勉強会への参加を会社が支援
- 入社後：最初の1か月はメンターが付き、開発環境の構築から並走します

じっくり設計に向き合い、長く使われるサービスを育てたい方のご応募をお待ちしています。
