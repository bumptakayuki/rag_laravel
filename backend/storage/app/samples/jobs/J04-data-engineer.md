# 求人票：データエンジニア

会社名：株式会社サンプルデータワークス
募集職種：データエンジニア

## 募集概要

株式会社サンプルデータワークスでは、社内の各部門が使うデータ基盤を構築・運用するデータエンジニアを募集します。現在は部門ごとにデータが分散しており、集計作業に時間がかかっています。そこで、データを一元的に集めて整理し、分析や業務改善に活用できる基盤づくりを進めています。

- 募集職種：データエンジニア
- 雇用形態：正社員
- 配属：データ基盤チーム（現在5名）
- 募集背景：データ活用の拡大に伴うチームの増員

## 業務内容

データ基盤の設計・構築から日々の運用までを、チームで分担して担当していただきます。入社後は既存のデータ処理の理解から始め、段階的に基盤の構築業務へ移っていただきます。

- 社内の業務システムからデータを収集し、蓄積するデータ基盤の構築
- Python によるデータ取り込み・加工処理の開発と保守
- SQL を用いたデータの集計・整形、分析用テーブルの設計
- データの欠損や重複を防ぐための品質チェックの仕組みづくり
- 分析担当者や事業部門からの要望のヒアリングと、データ提供方法の提案
- 設計内容や運用手順のドキュメント作成

## 必須条件

- データ基盤の構築に携わった経験（設計、開発、運用のいずれかを実務で担当したもの）
- Python を用いたデータ処理プログラムの開発経験
- SQL を用いたデータの抽出・集計・加工の実務経験
- 他のメンバーや他部門と円滑にコミュニケーションを取り、要件を整理できること

## 歓迎条件

- データ基盤の運用を継続的に担当し、処理の遅延やエラーの改善に取り組んだ経験
- 分析担当者や事業部門と協力してデータ活用を進めた経験
- データの品質管理や、データの定義を整理するルールづくりの経験
- 設計書や手順書を分かりやすくまとめた経験

## 開発環境・働き方

開発には Python と SQL を使用します。チーム内の連絡や相談は Slack で行い、仕様や手順は文書にまとめて共有します。事業部門との簡単な集計の確認には Excel を使うこともあります。

- 勤務形態：ハイブリッド勤務（出社は週2日程度、リモートと併用）
- 勤務時間：フレックスタイム制（コアタイムあり）
- 週次の定例会議で進捗を共有し、月に一度は改善点を話し合う振り返りを実施
- 勉強会への参加や書籍購入などの学習支援制度あり
