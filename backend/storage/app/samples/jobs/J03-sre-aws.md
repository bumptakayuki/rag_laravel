# 求人票：SRE（AWS）

会社名：株式会社サンプルクラウドワークス
募集職種：SRE（AWS）

## 募集概要

株式会社サンプルクラウドワークスでは、自社サービスの本番環境を支える SRE（AWS）を募集します。サービスの成長に合わせて、AWS 上の基盤をより信頼性が高く、運用しやすい形に育てていただくポジションです。

- 職種：SRE（AWS）
- 雇用形態：正社員
- 配属：プラットフォームチーム（SRE 担当）
- 募集背景：利用者の増加に伴い、本番環境の設計・運用を担う人員を増やすため

## 業務内容

本番環境の設計と運用を中心に、サービスの信頼性向上に取り組んでいただきます。

- AWS 上の本番環境のアーキテクチャ設計・構築
- コンテナ基盤の運用（デプロイ、スケーリング、障害対応、バージョン更新）
- 監視・アラートの設計と改善、サービスレベル目標の策定
- 障害発生時の一次対応、原因分析、再発防止策の実施
- 開発チームと連携したリリース手順や運用の改善
- 運用手順書・設計書の整備

入社後は既存の本番環境の運用を担当しながら、徐々に設計の見直しや新規構築にも関わっていただきます。

## 必須条件

- AWS を用いた環境構築の実務経験
- コンテナ基盤の運用経験
- 本番環境の設計および運用の経験（障害対応を含む）
- 開発チームなど他職種と協力して課題を進められるコミュニケーション力
- 障害の原因を筋道立てて調べ、記録として残せること

## 歓迎条件

- 大きなトラフィックを扱うサービスでの運用経験
- 監視体制や障害対応フローをゼロから整備した経験
- 可用性やコストを意識した構成の見直しを主導した経験
- 運用の自動化や効率化に取り組んだ経験
- 小規模なチームで、手順書づくりや後進の育成に携わった経験

## 開発環境・働き方

- 基盤：AWS 上のコンテナ基盤
- コミュニケーション：Slack、オンライン会議
- ドキュメント：Word、Excel などを用いた手順書・報告書

働き方は原則リモートワークで、必要に応じて出社します。オンコール対応はチームで当番制を組み、対応した翌日は勤務時間を調整できる体制です。

- 勤務時間：フレックスタイム制（コアタイムあり）
- 休日：土日祝日、年末年始
- 学習支援：書籍購入、勉強会参加の補助
