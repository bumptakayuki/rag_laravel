# Architecture

## 目的
候補者を「Laravel と Vue の経験がある5年以上のエンジニア」のような自然文で検索し、上位候補と根拠付きの推薦理由を返す。

## 処理の流れ
```txt
候補者（架空データ）
  → テキスト化（職種・スキル・経験・自己紹介）
  → EmbeddingProvider でベクトル化 → 保存          （RS-002〜004）
検索クエリ
  → EmbeddingProvider でベクトル化
  → 類似度 top-k                                     （RS-005）
  → 結果一覧                                         （RS-006）
  → LlmProvider が top-k を文脈に推薦理由を生成       （RS-007）
     ※ 文脈にない候補者 ID を含む回答は破棄
```

## 方針
- Laravel のモノリス。画面は Blade で始める（SPA にしない）
- 外部 API はすべてインターフェースの裏に置き、テストは Fake で行う（テストはネットワークを使わない）
- 候補者データは架空データのみ
